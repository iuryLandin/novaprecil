# Nova Precil em React

Recriação do site institucional da Nova Precil em React + Vite, com os ativos locais e rotas equivalentes ao site original.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
```

Os arquivos finais são gerados em `dist/`. O projeto inclui `.htaccess` para fallback das rotas React em hospedagens Apache.

## SEO

O projeto inclui metadados Open Graph/Twitter, canonical dinâmico, Schema.org (`LocalBusiness`, `FAQPage`, `ItemList` e `Product`), `robots.txt`, `sitemap.xml` e manifesto PWA.
